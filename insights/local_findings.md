## 7. 2026-09-25 新增（二）：我自己犯的两个测量错误

| # | 教训 | 代价 / 修法 |
|---|---|---|
| L13 | **`difflib.quick_ratio()` 不是相似度**——它是**字符多重集**的上界，对两个长 Python 文件会**饱和到 1.0**，把任何两个程序都排成"近克隆"。我在 `lineage_id.py` 里用它排"最接近的已知 agent"，于是所有输出都是 0.99–1.00 的废数 | 我据此错误宣称"gluzdov 的新 agent 与我们的 v34_base **token 集合完全一致**"。改成**按每 100 个 token 采样后的真实 `ratio()`** 后，真实值是 **0.605（ourv21/haideptry）→ 0.575（guru）→ 0.571（v55/prvsiyan/pipe16）**：同一 v9/3 祖先的**不同分支**，不是同一份代码。**L13 同时作废了此前所有基于 quick_ratio 的"相似度"排序**，需重估 |
| L13b | 反过来也不能用全长的 `ratio()`：两段 50 万 token 的 `SequenceMatcher(...).ratio()`（`autojunk=False`）是二次复杂度，**基本永不返回** | 我的一条后台命令因此白烧 CPU 25 分钟并拖慢了同时跑的阶梯。**正确做法：先按 stride 采样再做 `ratio()`** |
| L14 | **长任务不要接 `\| grep`**：grep 对文件是块缓冲（4KB），过滤后输出不够 4KB 就永远不落盘，看起来像"卡死" | 层阶梯跑了 25 分钟，`ladder.txt` 只有 74 字节（只有 shell 的 echo）。进程其实健康（8 个 worker 各累积 620 CPU 秒，仍在增长）。**改法：`python -u`，过滤放到事后** |
| L15 | **更好的血缘判据是"标识符集合差"，不是任何整体相似度** | 对 gluzdov 的 `more-wheat-smarter-sales` 做标识符 diff：他比我们 v34_base **多 32 个名字**——`_CXD_*` / `_cxd_agent`（**F4 层**）、`_CXTB_*`（counter-T-B 番茄门控）；我们比他**多 85 个**（`_33_*` KO/seedfloat/knock、`_ADV_BOOK`）。**这直接给出"前线多了哪几层"的清单** |

## 9. 2026-09-25：前线栈里有**重复层**（读 donor 源码得到）

准备 v42 时逐层读了 tetsutani 的 cha20 链，发现一个此前没注意到的结构问题：

| 层 | 小时窗口 | 前视 | 机制 | 依赖 |
|---|---|---|---|---|
| `_FX` FLOWPX | ——（流量触发） | —— | 跟随对手流量抢先卖 | —— |
| `_DP` DAWNPX | `{0,1,2}` | 8 步 | 磁带前视找计划卖单，现价 ≥ 近期均价就提前卖 3/4 | **`_FX_STATE` 的报价历史** |
| `_MP` | `{10,11,12,13}` | 8 步 | **同 `_DP`，逐字相同**，只换小时窗口 | 同上 |
| `_MPX` MODELPX | `{12..22}` | 1 步 | 用**引擎自己的价格曲线**做一步前瞻 | 自足 |
| `_SM` SHIELD-MILK | 全天 | —— | 给计划中的买入补钱 | 自足 |
| `_BD` BUYDIP | 全天 | 12 步均价 | 大额小麦买在均价之上时**拆单等候** | 自足 |

**三条结论：**

| # | 结论 | 证据 |
|---|---|---|
| M12 | **`_DP` 与 `_MP` 是同一个函数**（`_dp_apply` 与 `_mp_apply` 主体逐字相同），只有小时窗口不同 | 直接读源码；这也解释了阶梯里 **DP = 0、MP = −8pp** —— 同一想法的第二次应用几乎没有增量 |
| M13 | **`_DP`/`_MP` 不是独立的**：它们读 `_FX_STATE[player]["quotes"]`，没有 `_FX` 就没有报价历史，那句"现价低于近期均价就跳过"的测试会**静默失效**（`vals` 为空 → 不跳过 → 更激进地卖） | 直接读源码。**推论：单独移植它们会得到与原栈不同的行为**，这是移植的隐藏陷阱 |
| M14 | 因此 **MPX 是这一族里唯一"有模型"且自足的成员**，v40 已经拿到手；继续堆 DP/MP 属于**同想法重复**，预期收益低、风险是互相抢订单槽 | 阶梯数据 + 源码 |

⇒ **v42 改用 `_BD`**：阶梯里非零的层里，唯一**机制不同**（不买在高点，而不是早卖）且**完全自足**（只引用 `_BD_STATE`，不碰任何宿主内部）的那一个。

| M16 | **"v37/v41 vs v56" 是一个干净的实验**：它测的就是**我们自己那 123 个符号的净价值**。这比打 v55 或打公开 notebook 有意义得多——基准是同一个底盘 |
| M17 | 为什么我们对 **v55** 一直赢 93–96%：v55 是**上一代**，而我们在 v56 之上。**对上一代赢得多，完全不能说明我们对同代或更强的对手也赢** —— 这正是 L4"本地测试台有结构性空洞"的机制解释 |
| M18 | 反过来：**tetsutani_cha22 能压我们，说明它也在 v56 之上叠了有效的东西**（它借用 pipe18 的 e402/e410，而这些我们也有）—— 差距只能来自它自己那部分（cha20 链 + `_CXD`），与 v40/v41 的实测一致 |

## 11. 2026-09-25：`_BD`（BUYDIP）**被否证** —— 两块种子方向不一致

v42 = v41（v37+MODELPX+CXD）+ tetsutani 的 `_BD` BUYDIP 层。移植前的判断依据是
阶梯里它是"非零层里唯一机制不同且完全自足"的一个（`_bd_apply` 只引用 `_BD_STATE`）。

| | block A (1000-1049) | block B (4000-4049) | 合计 800 局 |
|---|---|---|---|
| v41（对照） | **87.2%**（349-51） | 86.0%（344-56） | 86.6%（693-107） |
| **v42（+BD）** | **86.2%**（345-55） | **86.5%**（346-54） | 86.4%（691-109） |
| 对 tetsutani_cha22 | v41 56% → **v42 52%** | v41 54% → **v42 56%** | —— |
| **最差单局** | v41 −$3,309 → **v42 −$10,316** | v41 −$4,148 → **v42 −$8,060** | —— |

**判定：不通过（拒绝）。** 依据两条，都不是"差一点"：

1. **两块种子方向相反**：block A 退化 1.0pp，block B 改善 0.5pp。按 L3（两块必须同向）即否决。
2. **尾部风险在两块都显著恶化**：最差单局从 −$3.3k/−$4.1k 恶化到 **−$10.3k/−$8.1k**。
   这与总量持平并不矛盾——**它在少数局里造成灾难性亏损，同时用一些局的微增掩盖了**。

### 机制假说（未单独验证，但与失败形状一致）

`_BD` 在现价高于 12 步均价时，**扣下最多一半的大额小麦买单**（上限 `_BD_CAP = 64` 单位），
等跌回均价或超过 6 步后才释放；而释放速率是**每回合 `min(pending, 8)` 单位**——
所以 64 单位要 **8 个回合**才放完。而"计划中的买入被扣下"正是**我们 M1 早死 bug 的同一个失败类别**
（现金/原料不到位 → 后续环节连锁失败）。

### 方法学意义

这是 L1/L2/L3 三条纪律同时生效的案例：
**阶梯里这一层"值 −8pp"是对 tetsutani 的栈测的，不代表叠到我们的栈上有用**——
层与层、层与底座之间不独立。**必须叠到自己身上测**，且**两块种子同向才算数**。

## 12. 2026-09-25：按商店世界切分胜率 —— **没有"世界性空洞"，弱点是对手性的**

工具：`scripts/world_split.py`（leoprovorov 的"评测单元是路线×世界"那条方法学）。
配置：v41 vs 6 个对手 × 50 种子 × 双座位 = **600 局**，在 **step 144**（路由器分叉点）读前两家已解锁商店。

**总胜率 547/600 = 91.2%，均差 +$1,155。**

### 按世界特征切（这些 n 够大，可解读）

| 特征 | 我们胜率 | n |
|---|---|---|
| **0 家奶店** | 91.7% | 216 |
| 1 家奶店 | 91.7% | 324 |
| **2 家奶店** | **86.7%** | 60 |
| 2 家番茄店 | 86.1% | 72 |
| 1 家番茄店 | 93.3% | 180 |
| 0 家番茄店 | 91.1% | 348 |
| 蛋店 0/1/2 | 89.6% / 93.0% / 83.3% | 288 / 300 / 12 |

- 方向上是"**越多奶店/番茄店略差**"，但 2 家奶店那格只有 n=60，5pp 的差距**远在噪声内**（n=12 的格子在 66.7%–100% 之间随机跳，正是这个噪声幅度的体现）。
- **按对手切才是清晰的**：tetsutani_cha22 **56%**（n=100），其余 5 个对手 **94%–100%**。

### 按座位的对称性检查（意外收获）

| 座位 | 胜率 | n |
|---|---|---|
| seat 0 | 91.7% | 300 |
| seat 1 | 90.7% | 300 |

⇒ **环境基本座位对称**（差 1pp，n=300）。这同时**收掉了 L5 那个悬案**（"镜像局不保证 $0 平局"曾被怀疑是环境座位不对称）——那是种子特定现象，不是系统性不对称。
