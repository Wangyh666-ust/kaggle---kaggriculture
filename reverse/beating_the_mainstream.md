# 如何击败主流对手 — 镜像局的决定因素与可制造的不对称

分析对象：本仓库全部 ladder 录像（`replays_v21/v23/v23r/v24/v24r/v25/v27/v28/ladder/ladder_ops`）。
所有结论都标注了样本量 n 与不确定性；凡是落在噪声范围内的效应，我都明确写"噪声"。
所有数字都由本文件第 5 节的命令在本机复现。

---

## 0. 摘要（先说结论）

1. **环境在座位上是精确对称的。** 把 `weedSpawnChance` 设为 0 后，`main.py` vs `main.py` 在
   20 个种子 × 2 个座位上跑 40 局，**每一局的 margin 都恰好等于 $0**（不是近似，是精确 0）。
   这否定了"座位优势 / 订单簿排队优势"这一类假设。
2. **镜像局唯一的隐藏随机源是杂草（weed）。** `_spawn_weeds()` 用
   `random.Random((seed * 1_000_003) ^ day)`，并且**先遍历 0 号农场的 100 格、再遍历 1 号农场**，
   而 `seed` 被环境主动对 agent 隐藏。因此镜像局的胜负主要是**关于种子的抽签**：
   自对弈 380 局中，**只有 9.5% 的种子会决出胜负**，且这 18 对**全部跨座位严格反对称**
   （18W-18L，mean 精确 $0）——**谁是赢家完全由种子决定，策略改变不了**。
   其余 90.5% 的种子是精确平局。
3. **一次随机杂草在 ladder 上平均值 −$401**（OLS，n=160，斜率 95% CI [−642, −161]，t=−3.27）。
   我们自己平均每局挨 0.65 次杂草，对手 0.83 次。
4. **我们的草有 71%（74/104）在被清掉之后再也没有补种**，对手是 47%（62/133）。
   逐格追踪的一局（seed 12 自对弈）显示：全程只有 2 次随机杂草，都在 0 号农场，
   其中 day 7 那一格被挖掉后**空了 16 天**，直接造成 −$1,264（就是该局的全部分差）。
5. 结论：**对真正的镜像，我们的结构性优势只有约 +$370~480**（去草消融测得），
   而杂草抽签能造成的摆动是 $53 ~ $1,264（中位数数百美元）—— 摆幅大于优势，
   这就是那 9.5% 的种子会输的原因；**它不是可优化的对局，是抽签**。

## 2. 镜像局到底由什么决定（全部有数据，不猜）

### 2.1 环境层面：唯一的隐藏随机源，以及它的精确结构

读 `.venv/Lib/site-packages/kaggle_environments/envs/kaggriculture/kaggriculture.py`：

```python
# _end_of_day()
rng = random.Random((seed * 1_000_003) ^ day)
for player_id, farm in enumerate(obs0.farms):
    ...
    _spawn_weeds(farm, board_size, weed_chance, rng)   # 0.005/格

# _spawn_weeds()
if farm["tiles"][y][x] is None and rng.random() < weed_chance:
    farm["tiles"][y][x] = {"kind": "WEED"}
```

由此可得三个可验证事实：

1. **随机杂草只长在空格上**（`is None`）。LOCKED 格不算空。
2. **两个农场的抽签来自同一条流**，0 号农场先抽（而且因为短路，抽数 = 该农场空格数），
   1 号农场的抽签起点因此**取决于 0 号农场当天的空格数**。
3. **种子被环境主动隐藏**（`resolve_episode_seed` 会把它从 configuration 里擦掉）。

**实测证据（消融实验）**

| 实验 | n | 结果 |
|---|---|---|
| 自对弈，`weedSpawnChance=0` | 40（20 种子 × 2 座） | **40/40 margin 精确 = $0**，sd = $0 |
| 自对弈，默认杂草 | **380**（190 种子 × 2 座） | 344 平、36 决出胜负（18W-18L），**mean 精确 $0.0**，sd **$166**，range ±$1,264 |

* 40 局精确为 0 ⇒ **环境在座位上完全对称，市场撮合也不偏袒任何座位**。
* 380 局里 36 局决出胜负，来自 **18/190 = 9.5% 的"决胜种子"**；
  这 18 对**全部跨座位严格反对称**（`margin(座0) == −margin(座1)`，18/18），
  即纯粹是种子发给谁的抽签，我们无法用策略改变谁是赢家。
* 决胜局的 |margin| 跨度 **$53 ~ $1,264**（中位数数百美元），
  正落在我们对镜像的结构性优势 +$370~480 的量级上 —— 这就是它们能翻盘的原因。
* 这一项**全部来自杂草**：杂草关掉后 40/40 精确 $0。

### 2.2 一局镜像的胜负手：一次杂草 ≈ 一次永久的计划中断

逐格追踪 seed 12 的自对弈（`scripts/weed_trace.py`）：

```
全局只有 2 次随机杂草，都在 0 号农场：
  step 168 (day 7)  seat0 RANDOM@(1,8)
  step 696 (day 29) seat0 RANDOM@(0,0)
最终  A $91,254   B $92,518   gap -1,264
```

格子 (1,8) 的完整生命史：

| | seat 0 | seat 1 |
|---|---|---|
| day 0–6 | LOCKED | LOCKED |
| day 7 | **WEED** | PLANT STRAWBERRY (planted_day=7) |
| day 8–23 | **None（空着）** | STRAWBERRY，day 17/19/21/23 各产 2 单位 |
| day 24+ | CARROT | CARROT |

即：**我们的一只手在 day 7 挖掉了那棵草，然后整个计划再也没有回到这一格，空了 16 天**；
对手在同一格收了 4 次草莓（≈ $1,024），差值就是全局面差 −$1,264。
**损失不是草本身，是草打断的计划没有被修复。**

### 2.3 在真实 ladder 语料上量化（clone 类 n=160）

用 `scripts/weed_cost.py` 逐日扫描 160 局，只统计"前一天是空格、隔天变成 WEED"的**随机**杂草
（植物枯死变草是确定性的，双方同计划时同时发生，已排除）：

| 指标 | 我们 | 对手 |
|---|---|---|
| 每局随机杂草数 | **0.65** | **0.83** |
| 清掉后再也没种回来的比例 | **74/104 = 71%** | 62/133 = 47% |

**回归（n=160）**

```
margin = +384 − 401 × (我方杂草数 − 对方杂草数)
斜率 95% CI [−642, −161]，t = −3.27   （即每多挨一次草 ≈ −$401）
```

**分组胜率**

| 条件 | n | 胜率 | 平均 margin |
|---|---|---|---|
| 我方杂草 ≤ 对方 | 131 | **60.3%** | +$589 |
| 我方杂草 > 对方 | 29 | **27.6%** | −$141 |
| | | Welch t = **+2.25** | |

**内生性检查**：我方杂草数 与 "step 359 时的领先额" 的相关系数 = **+0.007**，
即"打得好坏"并不预测"挨多少草"，反向因果的证据很弱（但不能完全排除，见第 4 节）。

### 2.4 消融：把杂草关掉，镜像局的输局全部消失

`main.py` vs 本地主流镜像，匹配种子 0–19 × 2 座（各 40 局）：

| 对手 | 杂草 ON | 杂草 OFF |
|---|---|---|
| v55 | 37W-3L, +$368 | **40W-0L, +$366** |
| prvsiyan | 35W-5L, +$333 | **38W-2L, +$335** |
| guru | 35W-5L, +$412 | **38W-2L, +$411** |

扩大到种子 0–29（60 局，去草）：**v55 = 60W-0L，平均 +$374，sd $254，最差 +$82**。

**读法**：去草后平均分几乎不变（+368 → +366），但**输局从 3 场变成 0 场**。
也就是说，我们对主流镜像的**结构性（代码）优势是 +$370~480**，
而输掉的那几局完全是杂草抽签造成的。

### 2.5 亏损是怎么积累的

* **开场 2 步的现金差**（sd 仅 $8）与最终 margin 相关 **−0.461**。
* **day 15（step 359）的领先额**：sd $339 → 最终 margin sd $1,651，
  相关 **+0.518**，斜率 **2.52**（95% CI [1.87, 3.17]，n=160）。
  ⇒ **中盘的 $1 差额到终局会被放大约 2.5 倍**；终局（day 15–29）不是"收尾"，是放大器。
* 首次"两个农场状态分叉"的原因（`scripts/divergence_trace.py`，clone 类 n=160）：
  MONEY 128 局（80.0%）、TILE_DIFF(1) 28 局（17.5%）、无分叉 3 局、随机草 1 局。
  中位分叉步 = **1**（因为 clone 类对手的第 1 步 wheat 单子各不相同，钱立刻就分叉了）。

## 3. 可制造不对称的具体机制

以下每条都给出：机制 / 预期效果 / 验证命令 / 验收门槛。

**统一验收基线**（必须先在**同一条命令**上跑 `main.py` 作为对照）：

```bash
.venv/Scripts/python scripts/tournament.py \
  --candidate main.py \
  --opponents opponents/v55/main.py opponents/prvsiyan/main.py opponents/guru/main.py \
  --seeds 2000-2039 --seats 0
```

**实测对照基线**（`main.py`，seeds 2000–2039, seat 0，120 局，272 秒）：

| 对手 | 战绩 | 平均 margin | 最差 margin |
|---|---|---|---|
| guru | 39W-1L-0T | +$510 | −$131 |
| prvsiyan | 38W-2L-0T | +$430 | −$205 |
| **v55** | **38W-2L-0T** | **+$362** | **−$405** |
| 合计 | 115/120 = **95.8%** | **+$434** | −$405 |

另一个参考点（seeds 1000–1019, seat 0，60 局）：v55 20W-0L +$439 / prvsiyan 19W-1L +$418 /
guru 19W-1L +$495。`v55` 是最纯的镜像（去草后 60W-0L，最差 +$82），
**新机制在 v55 上必须不掉胜场**。

---

### M1（最高置信度）杂草修复：被草打断的种植计划必须补种

* **机制**：维护一个"刚被清掉草的格子"队列。当某格在手挖掉草之后变空、
  而计划原本要在这一格种东西时，在接下来 K 天内（建议 K≤3）用空闲手或下一个可用当口
  补种同一作物。最朴素的形式：**当天的计划里要种的格子，如果发现是草，挖掉后必须把这条计划重新入队**。
* **证据**：71% 的草没被补种（74/104，n=160）；每株草 −$401（t=−3.27）；
  seed 12 的逐格追踪显示单株草造成 −$1,264。
* **预期效果**：clone 类每局 +$150~260（= 0.65 株 × $401 × 60%~100% 修复率），
  胜率上限从 56.5% 提到 **60.3%**（这就是"我方杂草 ≤ 对方"那一桶的实测胜率，n=131）。
  对高分段镜像（当前 47.1%）意义更大。
* **验证**：`experiments/weedfix/main.py` 作为 `--candidate`，跑上面那条命令（120 局 ≈ 4.5 分钟）。
* **验收门槛**（对照上面实测基线 115/120、+$434）：
  1. v55 的 mean margin 从 +$362 提升到 **≥ +$450**（即 +$88 以上，约等于消掉 2 株草）；
  2. 三个对手的合计胜率 **≥ 117/120**（即最多输 3 场，v55 最多输 1 场）；
  3. worst margin ≥ −$405（不得比基线更差）。
  若合计 mean 提升 < +$80 或 v55 输 2 场以上，判为噪声，放弃。

### M2（中等置信度）职业化"消草"：把随机草从抽签里删掉

* **机制**：草只能长在空格上。只要**日终没有空格**，随机草的概率就是 0。
  当前我们每局约 4.5 格（0.65 / 0.005 / 29）在日终是空的，正好是风险敞口。
  把最后这几格也种上（哪怕是低价值作物），抽签项就消失了。
* **证据**：`_spawn_weeds` 的短路条件；0.65 株/局；每株 −$401。
* **预期效果**：理论上限 = 把 clone 类 win% 从 56.5% 提到 60.3%、mean 从 +$457 提到 ≈ +$717
  （= +384 + 0.83×401，外推到 weed_diff=−0.83，略超出观测范围 [−4, +3]，所以是**外推**不是实测）。
  实际收益会小于上限，因为补种本身要花种子和手。
* **验证**：同 M1 的命令；候选是"日终空格数≤1"的变体。
* **验收门槛**：mean margin ≥ +$150 且 **不增加非 DONE 局**。
  注意这条与"把地种满"这个通用强度提升是重合的，不要重复计功。

---

### M3（潜力最大、但未证实因果）把 day 0–1 的开场单子当一等变量去调

* **机制**：在 clone 类内部，**对手第 2 步（index 1）的 market 单子把结果劈成了两半**：

  | 对手 index-1 单子 | n | 我们胜率 | 平均 margin |
  |---|---|---|---|
  | `BUY_PRODUCT WHEAT 20, SELL WHEAT 15` | 62 | **74.1%** | +$940 |
  | `BUY_PRODUCT WHEAT 20, SELL WHEAT 15, BUY_SEED WHEAT 1` | 58 | **37.5%** | −$299 |

  只差一个 **$10 的麦种**，胜率差 **36.6 个百分点**。
  **版本对照后该效应仍在**：v23 91.7%(n=12) vs 31.2%(n=16)；v24 80.0%(n=20) vs 56.5%(n=24)；
  v24r 60% vs 60%（n=10/10，无功效）。
* **风险**：这很可能只是"对手血统"的标记（抄了新版公开 agent 的队伍更强），
  未必是"多买一个麦种"本身带来的因果收益。**我没有把它证成因果。**
* **预期效果**：不确定。如果有一半是因果，这是全场最大的一根杠杆（36pp）。
* **验证**：在**策略内部**改开场（`Chassis`/EXP-173 那一层），用同一条 tournament 命令 A/B。
* **验收门槛**：mean margin ≥ +$300（明显高于 M1/M2 的门槛），或 clone 类胜率 +3pp 以上。
* **反面结果（已实测，必须记下）**：我尝试用"外层 wrapper 在第 1 步改写 market action"来做这个实验
  （`experiments/open20/main.py`），**失败**：seed 3 对 v55 的 margin 是 **−$88,919**
  （reward $20,865 vs $109,784）。原因是我们 agent 内部有与下单绑定的账目状态，
  外部改写 action 会把它打乱。**这条机制只能在策略内部实现，不能事后补丁。**

---

### M4（置信度中，与前三者正交）终局放大器的管理

* **机制**：step 359 的领先额到终局被放大 **2.52 倍**（95% CI [1.87, 3.17]，n=160）。
  这意味着 day 15 之后的每一个决策（尤其是库存清算、动物出栏、终局甩卖）
  在金钱上比中盘同等动作重要 2.5 倍。
* **预期效果**：把终局清算做得更激进/更早，理论收益与 M1 同量级。
* **验证**：同一条命令，候选是终局层变体。
* **验收门槛**：mean margin ≥ +$150，且 worst margin 不变差。

## 4. 我否决的假设（负面结果）

| # | 假设 | 为什么否决 | 证据 |
|---|---|---|---|
| 1 | **座位不对称决定镜像局** | 去草自对弈 40/40 局 margin **精确 = $0**；带草自对弈跨座位严格反对称（±1264）。环境在座位上完全对称。ladder 里"座1 胜率更高"（62.1% vs 52.3%，p=0.049）是对手抽样混杂，不是座位效应。 | `mirror_probe --mode noweed`，n=40 |
| 2 | **同单抢跑 / 订单簿排队优势** | 同上。若存在"先挂单先成交"的座位优势，去草自对弈不可能 40 局全是精确 0。市场撮合对相同订单是对称的。 | 同上 |
| 3 | **亏损集中在特定 shop-pair 世界** | clone 类 160 局落在 **59 个不同的 pair** 上，最大的一桶只有 n=9（BRUNCH_SPOT+PIZZA_SHOP，8W-1L）。**完全没有统计功效**，任何"某个 pair 会输"的说法都是噪声。 | §5 复现脚本 `clone_analysis.py` |
| 4 | **恢复种子 ⇒ 预测杂草 ⇒ 免疫** | 理论上信息足够（每天约 7.6 bit × 29 天 ≈ 220 bit > 31 bit 种子），但**算力上不可行**：需要在局内枚举 2³¹ 个候选，每个候选构造 `random.Random()`，第一轮过滤就要 ~1 小时/局；而且 ladder 种子没有小池子可查表（455 局 **455 个不同种子**，全部是 31-bit 随机数，唯一的 seed=0 是 3 局自对弈）。 | §1.1 种子分布；环境源码 |
| 5 | **`n_diff_steps` 小 = 真镜像 = 我们应该赢** | 反了。差异 ≤20 步的 21 局我们 **4W-12L-5T，平均 −$8**。而且 clone 类里中位差异是 96 步/720，只有 13.1% 算得上接近逐字节 —— 说明"同签名"分类的是**计划族**，不是同一份代码。"最像我们的对手"我们并不占优。 | clone 语料 n=160 |
| 6 | **"我们有时漏买第 1 步的麦种"导致 14.3% 胜率** | **版本混杂**。漏买麦种的 25 局 clone 局、72 局 other 局，**100% 来自 `replays_v21`**。这正是 v21→v23 的开场改动，不是当前 agent 的活缺陷。当前 v25+ 的 63 局**全部**买了麦种。 | `clone_dataset.py` + 版本交叉表 |
| 7 | **杂草损失主要是"草本身占格"** | 不是。草通常在当天就被挖掉了（seed 12 里 day 7 出现、day 8 就没了）。**真正的损失是计划没被修复**——那格空了 16 天。所以正确的机制是"补种"（M1），不是"更快挖草"。 | `weed_trace.py --seed 12` |
| 8 | **杂草效应全部是因果** | 保守地说，ladder 上的 −$401/株 是**观测回归**，杂草数部分内生（空格多的局更容易长草）。干净因果证据只有自对弈消融（n=40+80）和本地消融（n=120）。我用"step 359 领先额 vs 我方杂草数"做了反向因果检查（corr = +0.007），没有发现证据，但不能完全排除。 | §2.3 |

## 6. 一句话行动建议

**先做 M1（杂草补种）**：它证据最硬（71% 未补种、每株 −$401、t=−3.27）、
