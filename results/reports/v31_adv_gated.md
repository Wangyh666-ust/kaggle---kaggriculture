## 1. 动机（为什么做门控）

v30 的结论（`results/reports/v30_prvsiyan_layers.md`）是一条干净的机制：ADV 是**纯零和抽取层**——我方 reward 不动（Δ `−$63 / +$61`），对手 reward 掉 `−$701 / −$426`；边际大涨（`+$434 → +$1072`），但**胜率净输 21 局**（n=240，翻转 24 负 : 3 正，p=2×10⁻⁵），镜像却极显著为正（150/200 = 75%，z≈6.6）。

v30 §8 给出的第 2 条后续建议就是本次任务：

> **把 ADV 门控到"已识别为克隆"的对局。** ADV 在镜像 z≈6.6，在近亲面板显著负——**这正是"应该只在克隆域打开"的教科书形状**。

本报告检验这个假设：**门控能否保住镜像增益、同时消除非克隆域的胜率回归。**

## 2. 找门（本节是本次最有价值的部分）

任务书要求"复用仓里已有的对手识别机制，不要自己发明"。我逐个测了 `main.py` 里现成的信号，结论如下。

### 2.1 现成的门**全都不能用**（逐条实测）

测法：`main.py` 当选手，对 8 个对手 × 10 个种子（seed 2000-2009，seat 0），dump 模块级 `_RACE_REPORT` 与逐步特征。工具：`scripts/adv_gate_probe.py`、`scripts/adv_gate_features.py`。

| 现成信号 | 实测 | 判定 |
|---|---|---|
| `_race_clone` / `_v44y_clone_gate`（手位锁步 + `_r37_similarity ≥ .95`） | **对 8 个对手一律触发 476/480 回合** | ❌ **不是门**。因为它对**所有**对手都开，`_v44y_clone_gate` 恒为 True |
| `farmer` 位置相同 | `719/719`——**全部 8 个对手，每一回合** | ❌ 同上：整个 agent 家族共用同一套路线扫描 |
| `hands` 位置相同 | `688/719`（main/v55/prvsiyan/v23c7/v25/v26/v27）、`634/719`（guru）、`0/719`（内置 starter） | ❌ 对本家族无区分度 |
| 瓦片作物布局相同率 / `_r37_similarity` | `sim ≥ .95` 在 `700–708/719`（**guru 也有 700**） | ❌ 全家族同一套计划 |
| **卖单 tape 一致率**（我方有卖单的回合中，对手卖单流逐字节相同） | main **100%**、v27 99.6%、**v26 98.7%、v55 98.7%**、prvsiyan 95.0%、guru 94.5%、v23c7 93.6%、**v25 93.6%** | ❌ **关键负面结果**：公共面板（v55/prvsiyan/guru）与我们自己的旧版（v25/v26/v27）**在 tape 上完全无法区分**。v55 与 v26 一模一样（98.7%），v25 比 guru 还差 |
| `_RACE_STATE['race_escalations']`（`_race_lost`，对手抢跑我方卖单） | 每局 `0.0–0.5` 次 | ❌ 触发太稀疏，做不了门 |
| `_V92_P`（对手卖单流预测库）/ `_V93_ROUTE_BY_RIVAL`（`CT_TABLE` 路线表） | **未逐条实测**（任务书已指出 `CT_TABLE` 系 stale、线上几乎不触发） | ❌ 不采用 |

**这一节本身就是一个结论**：本仓现成的克隆识别机制（位置锁步 / 瓦片相似 / 路线表）**全部在本家族内失去区分度**——因为对手和我们共用同一套移动与种植计划。**能区分的不是"做什么"，是"第一回合的现金对账单"。**

### 2.2 采用的门 G1：**第一回合现金往返一致**

```
在 step == 1 时一次性读取（之后锁存）：
    G1 = abs(farms[我].money - farms[对手].money) < $0.5
```

语义：**对手第 0 回合的市场动作与我们产生了逐分相同的净现金流**。因为双方起始资金完全相同，这就是"对手第 0 回合跑的是我们那份单子"。

**与字节级签名的等价性（本地实测）**：`adv_tape_features.py` 抓取了双方每一步的**真实 market 单子**（包住对手模块，仅用于测量）。8 个对手 × 5 种子 = 40 局，`G1` 与"两侧第 0 回合 market 列表逐字节相同"**40/40 完全一致**。

### 2.3 G1 的实测精度与触发率

**(a) 本地面板**（`scripts/v31_telemetry.py`，8 对手 × 10 种子）：

| 对手 | G1 开 |
|---|---|
| `main.py`（真镜像） | **10/10** |
| v25 / v26 / v27（我方旧版） | **各 10/10** |
| v23c7（我方旧版） | **0/10** |
| v55 / prvsiyan / guru（公开面板） | **各 0/10** |
| 本任务书三块面板合计 | 公共 **0/240**、近克隆 **120/160**、`main.py` **100/100** |

**(b) 线上 538 局 ladder 语料**（`scripts/adv_gate_ladder.py`，直接读 589 个 replay 的 `steps[1]` 双方 money，排除自对弈）：

| 子集 | n | 胜率 | mean margin | 中位 margin |
|---|---|---|---|---|
| 全部 ladder 局 | 538 | 68.4% | +$6,628 | +$1,475 |
| **G1 触发** | **64 = 11.9%** | **40.6%** | **+$72** | **−$2** |

- **触发率 11.9%**（不是 90%，也不是 2%）。
- **精度 94%**（64 局里 60 局属于 ladder 克隆类）。只有 4 局是"非克隆却触发"，这 4 局我们 0W-4L。
- **G1 恰好筛出我们最输的那批对局**：触发时胜率 40.6%，静默时 72.2%。这在机制上正是 ADV 想要的域（接近五五开），也正好是方差最危险的地方——**门的两面性从这一步就注定了**，见 §5。

**G1 vs 字节签名**：线上 G1 是签名的**严格超集**（40 局两者都有，24 局只有 G1）。那 24 局是"净现金相同但单子结构不同"，胜率并不更差，所以我用了更便宜也更宽松的 G1，并把"我实现的是 G1、线上数字也是按 G1 统计的"写清楚。若改用字节签名，触发率降到 40/538 = **7.4%**，触发域胜率 30.0%。

## 3. 改动内容

### 3.1 移植方式

`main.py` 全文之后**纯追加**（`diff <(head -7374 候选) main.py` 为空），不重绑任何既有层；入口点自检打印 `agent True`。

相对 v30 的两处改动：

1. **删除 R148 整块**（`_r148_overflow` / `_r148_atomic` / `_r148_seed_prefund` / `_R148_*` 常量）。理由（v30 §4.5、§6）：触发 3/40 局，8/8 局变差（每次 −$42~−$87），且 `_r148_seed_prefund` 引用了本线已删除的 `_r128_future`（潜在 NameError）。
2. **ADV 整块（`_adv_apply` + `_adv_frontload`）放进门后**：门关时 ADV 完全不执行，市场单原样透传（§7 遥测：`gate_open=0 ⇒ adv_turns=0`）；IG 不门控（v30 实测 IG 面板代价 ≈ 0，本次 §5.1 复核为 ±$4）。

门自身零成本：每局只在 `step==1` 读一次 money，之后读一个 bool。

### 3.2 层定义（逐字来自 v30）

- **ADV（EXP293，sale advance）**：`_ADV_LOOK=4`、`_ADV_FROM=144`、`_ADV_TO=718`，若原生 tape 未来 4 回合内有 `SELL` 纯现金产品且货已在棚里，**现在就卖**；保护下一回合第一单；`_adv_frontload` 把市场单重排为 `纯SELL → BUY_PRODUCT → 其余`。
- **IG（EXP258，保守闭合）**：`_ig_guard_opening`（**实测恒不触发**）+ `_ig_close_queue`（把"投影仓里无货"的现金 `SELL` 变成空洞并左移填洞，**不改任何物理动作与数量**）。

### 3.3 变体

- `abl_ungated.py`：门强制常开（`if True:`），其余逐字节相同 → **对照 v30 去 R148 版**。
- `adv_gated_strict.py`：动态门——**锁步必须当回合仍成立**，第一次资金分叉即永久关门。

### 5.5 动态门变体（`adv_gated_strict`）——一个自毁的设计

| 测试 | 结果 |

| 公共面板 A | 115/120 / +$438 / −$405（✅ 同门控版） |
| 近克隆面板 A | **145/160** / +$320 / −$948（对比基线 151/160 / +$339；翻转 6 负 : 0 正） |
| 头对头 2000-2099 | **77/100 = 77.0%**，但 mean margin **+$6** |

**遥测揭示它为什么退化**：`adv_turns = 1`、`adv_units = 2`——**每局只跑 1 个回合**。因为 ADV 一旦卖出，**我方现金立刻与对手分叉，门当回合就永久关闭**。动态门**被它自己门控的层触发关闭**。

副作用是一个有意思的观察：**一个回合、2 个单位的提前卖出，就能把镜像胜率从 50% 打到 77%**（mean margin 仍只有 +$6）——镜像局的胜负确实由"谁先制造不对称"决定，这印证 `reverse/beating_the_mainstream.md` §2.1 的"9.5% 决胜种子 + 抽签"图景：**制造不对称比抽签便宜得多**。

## 6. 门槛判定

| # | 门槛 | A 池 | B 池 | 判定 |
|---|---|---|---|---|
| 1 | 公共面板 ≥ 115/120（硬） | 115/120 | 117/120 | ✅ **通过** |
| 2 | 近克隆面板 ≥ 基线 +8/160 | 136 vs 151（**−15**） | 146 vs 155（**−9**） | ❌ **失败** |
| 3 | 对 `main.py` ≥ 60% | 78/100 | 72/100 | ✅ **通过** |

**三条是 AND → 预登记判定为 ❌ 否决。**

**但这不是一次"平淡的失败"，必须把分裂点单独列出：**

- **门控假设的**核心主张**被证实了**：门把 v30 的公共面板回归（`115 → 103`）整块消除（`115 → 115`，逐局零翻转），同时保住了镜像增益（`78/100`、`72/100`，与 v30 的 150/200 一致）。门本身便宜、精确（线上精度 94%、触发率 11.9%）、可解释。
- **失败的是"近克隆面板会净赚"这个前提**。近克隆面板基线就赢 94.4%，ADV 在那里 **$427/局 的抽取全部以方差形式结算，净输 24 局**。门只能决定"在哪开"，不能改变"开了之后是正是负"。
- **两块种子池一致**（−15、−9），合并 p ≈ 10⁻⁵，不是噪声。

**线上期望值：我给不出可信的正号。** 门的真实作用域（G1 触发）在 538 局 ladder 语料上是 **占总局数 11.9% 的、我们历史胜率仅 40.6% 的对局**。这个 40.6% 落在两个本地代理**之间**：`main.py` 头对头（基线 50% → 75%，**正**）说应该赚；近克隆面板（基线 94.4% → 85.0%，**负**）说不该赚。**本地面板没有第三个体量来判定 40.6% 这一点，我不做外推。** 按本仓规则（宁可漏掉，不可烧分），**否决**。

**要判定这一点需要什么**：需要一个"我们本地胜率 ≈ 40–50%、且第一回合与我们同 tape"的对手。**在本次测过的 8 个对手里不存在**——能通过 G1 的只有我们自己血统的版本，而其中除 `main.py`（基线 50%）外的都在 90%+。所以这不是"n 不够"，是**本地可构造的对照里有系统性缺口**，必须用**受控线上 A/B** 才能闭合（并且要按 `results/score_is_opponent_draw.md` 的口径把"被排到谁"的方差扣掉）。

## 9. 决策与后续

**否决本改动**（不合并进 `main.py`）。

理由排序：

1. 预登记门槛 3 条只过 2 条，失败的是**近克隆面板胜率**，且在两块独立种子池上复现（−15、−9），合并 p ≈ 10⁻⁵。
2. **门控本身是成功的，但它成功地把回归搬到了"门打开的地方"**——而那正是门的全部意义所在。门开 = 对手是近克隆 = 我们本来赢 94%。ADV 的 $427/局 抽取在那里净输 24 局。
3. 线上期望值不可判定（§6）：门的真实作用域是 ladder 上 11.9% 的对局，其历史胜率 40.6%，两个本地代理给出相反的符号。**没有第三个本地体量可以裁决。**

**保留的正面资产**（后续可复用，不需要重新发现）：

1. **G1 门本身**：`abs(money[我] − money[对手]) < $0.5 @ step 1`。便宜、零重构、零状态、本地 240/240 公共面板不触发、线上精度 94%。任何**未来需要"只在真镜像上开"**的层（例如 §5.5 那个"一回合制造不对称"的层）都应该直接用它。
2. **§2.1 的负面清单**：`_race_clone` / `_v44y_clone_gate` / 瓦片布局 / tape 一致率在本家族内**全部无区分度**的实测数字，可以省掉后续重复劳动。

**若要继续走这条线，按优先级：**

1. **把 ADV 从"克隆门"改判为"接近度门"**。本次数据强烈提示真正的调节变量不是"是不是克隆"，而是**基线胜率离 50% 有多远**（§5.4：0–200 桶 111 局是决胜区，≥600 桶候选只在 45% 的局里更优）。可行的表述是"只在终局前领先额落在某个区间时开 ADV"，或者"只在 step 359 领先额 < $X 时开"。**这必须先单独预登记、并用两块种子池放大到 n≥400。**
2. **只移植 IG，不要 ADV**（v30 §6.1 的老建议，本次未变）：面板代价 ≈ 0，`opening_repairs` 恒 0 说明 `_ig_guard_opening` 是死代码应删。
3. **门槛 2 这条判据本身值得修**：用"我们本地胜率 94.4% 的旧版"当 ladder 克隆类的代理，与 ladder 上克隆类 61.1%（G1 域 40.6%）的难度**差了一整个量级**，任何抬方差的层在这条判据上都会必然失败。建议后续预登记改用"基线胜率 40%–60% 的对手面板"（本次测过的 8 个对手里没有这样的对手，需要先构造）。
